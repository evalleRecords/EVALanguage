🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Connection refused" when accessing http://localhost:3000/api/health
Solution: Make sure npm start is running. Run: npm start

Problem: "Cannot find module 'pg'" or similar
Solution: Run: npm install

Problem: No data showing in calendar after taking quiz
Solution: Take quiz first, then refresh progress.html

Problem: API not responding
Solution: Check .env file - DATABASE_URL must be correct

Problem: ".env file not found" error
Solution: Create .env file manually in root folder with DATABASE_URL

Problem: CORS error in browser console
Solution: CORS is enabled. Check that API_URL in JavaScript matches server URL
